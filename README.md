# TalentHub Frontend

A responsive HTML, CSS and JavaScript frontend starter for a creative talent marketplace.

## Files
- `index.html` — page structure
- `css/style.css` — styling and responsive layout
- `js/app.js` — demo data, navigation, search, filters, profile editing and subscription placeholders

## Run locally
Open `index.html` in a browser, or upload the project to GitHub and enable GitHub Pages.

## Important limitations
This is a frontend demo. Creator cards use sample data. Profile editing uses browser localStorage only. Login, database, messaging, file uploads and payments are not implemented.

For production, connect a secure backend and database. Payment orders and payment verification must happen on the server. Never expose payment secret keys in frontend code.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all files while keeping the `css` and `js` folders.
3. Open repository Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.
